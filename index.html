🔗 Google Sheets Connection

วาง URL หลัง Deploy Web App จาก Google Apps Script

💰 วงเงินรับซื้อสูงสุดต่อวัน

⚠️ สำหรับกรณีฉุกเฉินเท่านั้น — ค่าเริ่มต้น 2,000,000 บาท

📋 คำแนะนำการเชื่อม Google Sheets

1. เปิด Google Sheets สร้าง Spreadsheet ใหม่
2. ไปที่เมนู Extensions → Apps Script
3. ลบโค้ดเดิมออกทั้งหมด แล้ววาง Code จากไฟล์ farevefarm-apps-script.gs
4. คลิก Save แล้วกด Run → setupSheets ครั้งแรกเพื่อสร้าง Sheets
5. กด Deploy → New Deployment → Web App
   — Execute as: Me
   — Who has access: Anyone
6. คัดลอก URL และวางในช่องด้านบน
7. กด "ทดสอบการเชื่อมต่อ"
